Bonus system map

Every bonus the game applies, which bracket it lands in, and the cap that stops it. Companion of docs/BONUSES.md (the agent-readable version). Constants named here are the source of truth; change them in code, then update this page and the test mapping.

1. Economy: resources per second

One function combines it all: calculateResourceBreakdown in src/utils/game/income.ts. Tick, offline grant and server summary all call it.

BASE (summed)
  • Realm base (gold 0.1, xp 0.25)
  • Farm output x (1 + Scarecrow% + gear Farm Yield%)
  • Tiles: rate x 1.3 x (1 + 0.25 x same-biome neighbours)
  • Producers + Extractors
  • Castle area bonus: each tile in range adds its output x bonus
  • Castle flat XP: 0.5 x (level - 1)
x
1 + ADD% bracket
  • Castle level (20% doubling to L6, then +320%/lvl; L10 = +1920%)
  • Imperial Decree doubles the castle term
  • Plains meat +5% per plains tile (meat)
  • Attributes 2.5% per point
x
MULT buckets
  • Ember: 1 + 0.12 x earned^0.6
  • Foreman: 1 + 1%/lvl + Overseer 3%/lvl (not XP)
  • Gear income (cap 50) x Paragon income (0.8%/pt, 25 pts) (not XP)
→
CAP
  • Stockpile 1e21
  • Offline: 72 h, 100% efficiency
Example: base 100/s, castle L10 (+1920%), Ember x2.0, gear +50%, no other bonus → 100 x (1 + 19.2) x 2.0 x 1.5 = 6,060/s. The castle term is added to other additive bonuses; Ember and gear are multiplied.

Built once per fight by playerProfile() (src/lib/offline/profile.ts); the character window mirrors it in effectiveStats().

BASE
  • Weapon / gear damage (level scale x quality x rarity)
x
ADD% bracket
  • STR 2%/pt (INT 2.4%/pt for staff/wand), above 5
  • Merchant: Might / Arcana
  • Ember: Brawn / Sorcery
x
gear damage %
  • Sets + legendary perks, summed then capped 50
x
Idol / Watchtower / Paragon
  • Blight Idol 2%/lvl, Paragon 2 x sqrt(pts)
  • uncapped
x
Mastery
  • vs that monster type, cap 20
→
monster armor
  • x (1 - armorReduction)

Offence

  • Crit chance clamp 75, super crit 50
  • Crit damage: x2 / x5 times (1 + attr% + min(gear,50)%), then x Paragon crit
  • Attack speed: additive bracket, gear share cap 25
  • Armor pen cap 30

Defence

  • Armor = a / (a + 40), halved past 0.5, ceiling 75%
  • Dodge cap 40 (gear only)
  • Max HP uncapped: (85 + 3 VIT + 0.25 CHA + gear) x gear% x Idol
  • Leech cap 15 (Paragon/Idol after), thorns 25, heal on kill 8

Potions

  • Power cap 50 (Paragon after)
  • Slots max 5, cooldown floor 4 s
  • Max 5 buffs at once

3. Kill rewards and loot

BASE
  • min(income/s x rewardSec, monster cap) x levelMult^(L-ref)
x
gold only
  • (1 + 0.005 x Luck)
  • (1 + Gold Find%) uncapped gear part
x
MULT buckets
  • Golden x3
  • (1 + Kill Rewards%): gear cap 60 + Idol + Paragon 1.5 x sqrt
  • (1 + mastery gold/xp, cap 25)
  • (1 + deed, cap 5)

Gear drops: rolls x (1 + 0.002 x Luck) x (1 + mastery loot); rarity weights of rare+ x min(1.6, 1 + 0.004 x Luck) x (1 + Epic Find%), epic pity +5% per miss up to x3. XP is not touched by Luck or Gold Find.

4. Sources by system

Castle

src/config/castle.ts, src/lib/castleWard.ts

  • ADD% level modifier, L10 = +1920%
  • BASE area bonus +50% below L7, then radius x 100% (+400% at L10, radius 4 = 9x9)
  • Ward from L7: no monsters or chests in range
  • L11-15 only with Castle Expansion; range and area do not grow past L10

Adjacent tiles

SCALING_CONFIG.adjacencyBonus in src/config/economy.ts

  • +25% per same-biome 4-neighbour: x1.0 to x2.0 per tile
  • Castle tile gets none; Producers/Extractors are not neighbour based
  • Producer size bonus: +2% per owned tile of its biome, cap +100%, plus biome milestones +25%

Buildings and Idols

src/config/buildings.ts, src/lib/idolEconomy.ts

  • Producer/Extractor: BASE into income
  • Idols 2%/level, general buildings 1%/level/copy: fields of IdolEconomy (XP, damage, HP/armor, kill rewards, offline, click, sell, luck, chest speed, build time)
  • Build time total cap 60%

Paragon

src/config/paragon.ts

  • Capped: rate x min(points, 25)
  • Uncapped: rate x sqrt(points) (100 pts at k=2: +20%, 1000 pts: +63%)
  • Combat: critDamage, bossTimer, lifeLeech (capped), damage, maxLife
  • Economy: income, xpGain, tileDiscount (capped), clickGold, killRewards
  • Fortune: luck, goldFind, goldenChance (capped), chestDrop, epicFind
  • Realm: offlineEff, buildSpeed, potionPower (capped), paragonXp, craftXp

Merchant (gold shop)

src/config/merchant.ts

  • Economy: Haggler 3% sell, Foreman 1% income, Skinner 5% meat/hide, Charm 2 luck, Bulk 1pt tile discount
  • Combat: Quick Hands, Keen Eye, Deadly Aim, Might, Arcana, Vampiric Fang, Second Wind
  • Costs: ceil(base x growth^level); levels 6-10

Ember shop (rebirth)

src/config/rebirth.ts

  • Permanent twins of merchant upgrades plus cap-raisers: Castle Expansion (10 to 15), Treasury Charter (+3 discount cap/lvl), Imperial Decree (castle x2), Master Masonry, Idol Mastery
  • Ember income multiplier is global and never lowered by spending

Gem store

src/config/gemShop.ts

  • No production or combat stat
  • Additional Builder (max 3), Master Workbench +0.5 craft speed, Overnight Orders +24 h, Bulk Discount -10% craft cost, Building Slot +1 copy
  • Cosmetics and respecs only otherwise

Gear, sets, attributes

src/catalog/perkCaps.ts, src/lib/inventory.ts

  • Items + affixes + legendary perks + set bonuses summed, then capPerks
  • Attributes: base 5, bonuses above it; budget per level + 20 per rebirth
  • Classes: small flat passives

7. Known drift and loose ends

  • Uncapped stacking bypasses the gear caps: Idol/Building damage, Paragon crit damage and life leech, Idol/Paragon kill rewards and XP, gear Gold Find. Owner decision needed.
  • Guest saves stamp only damage, HP/armor and sell into idolFx; guest fights skip Paragon maxHp, critDamage, lifeLeech, bossTimer and potionPower.
  • Epic Find also lifts rare weights (text says "epic and better").
  • Paragon Gold Find does not affect sell prices (blurb says "drops and sales").
  • Idle HP regen display includes the base 1 HP/s; the in-fight profile does not.

8. When you change a bonus

  1. Edit the constant and its JSDoc (@category, @formula).
  2. Update the row in docs/BONUSES.md and here, including the cap comment marker and its mapping in tests/docs/bonuses.test.ts.
  3. Say which bracket a new source lands in (BASE / ADD% / MULT) and which cap stops it.
  4. Run npx tsx --test tests/docs/bonuses.test.ts, then npm run verify.
