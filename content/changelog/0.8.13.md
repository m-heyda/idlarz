# 0.8.13 - Leaving the game running is fine
date: 2026-11-19

- **Leaving the game open all night, or using an auto-clicker, no longer holds your account back.** A castle or building timer that looks a little early, or play time that runs ahead of the clock, is now only noted. It no longer cuts your income, chest rewards or offline pay, and it no longer takes you out of the rankings.
- **Idols catch up after a long idle run.** An Idol you raised while the game was left open is now counted by the server even when several levels came between two saves.
