# kenney-interface-sounds

Three picked sounds from the CC0 Kenney "Interface Sounds" pack (licence in `LICENSE.txt`). **Not wired into the game yet** (`src/utils/audioManager.ts` loads only the four game mp3s). They are no longer listed in the asset library or Storybook; this file keeps the owner's notes on where each one goes.

| File | Length | Planned use |
| ---- | ------ | ----------- |
| `click_003.wav` | 0.02 s | clicking when adding stats, or the double click to use an item |
| `glass_004.wav` | 0.71 s | collecting crafting results |
| `maximize_008.wav` | 0.24 s | minimizing the battle window |
