# trees_mapp_details (164 files)

Trees for the map: 12 kinds, 3 to 4 sizes each (small, medium, large): Autumn tree, Broken tree (cut trunk with one leaf), Burned tree, Christmas tree, Flower tree (pink), Fruit tree, Moss tree, Palm tree 1 and 2, Snow Christmas tree, Snow tree, plain Tree, plus stumps, logs and dead roots. Sizes 16 to 800 px wide (the biggest files are the source sheets).

Layout: `Assets_separately/Trees`, `Trees_shadow`, `Trees_texture_shadow`, `Trees_texture_shadow_dark` (40 objects each) and four `*_source.png` sheets. Use one variant; the grass-texture shadows sit on green ground.

**Use for**

- Biome decor props: forest (Tree, Moss, Fruit), tundra (Snow tree, Snow Christmas), Fields and Orchard (Fruit, Flower tree), Jungle (Palm 1 and 2), Blight (Burned, Broken), swamp (Moss).
- Wood tiles later (stumps and logs when a lumber building works the tile).
- Tile friendly: small and medium sizes (16 to 48 px) fit one 48 px tile, large ones span two.
