# minerals_map_details_or_resources_crafting_etc (164 files)

Crystals and ore nodes, 10 kinds in 4 sizes: Black, Blue, Dark red, Green, Pink, Red, Violet, White, Yellow-green, Yellow. Same layout (`Assets`, `Assets_shadow`, `Assets_texture_shadow`, `Assets_texture_shadow_dark`, `*_source.png`). Sizes 16 to 640 px (the sheets are the large files). The folder name already says the intent: map details, resources, crafting.

**Use for**

- Gatherable resource nodes on the map and in the Mine and Extractor buildings (`docs/plan/18-biome-buildings-and-material-tiers.md`): Iron Ore (blue or black), Salt (white), Pearls and Frostshard, Corrupted Core (violet), Ichor (dark red), Honey crystals (yellow).
- Material icons for the T2 and T3 resources of the rebirth biomes (the existing art in `public/pixel/resources` wins where it exists).
- Crafting window ingredient icons: one colour per extract makes recipes readable.
