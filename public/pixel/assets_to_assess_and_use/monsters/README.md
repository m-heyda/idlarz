# monsters (11 files)

Monster sprites added 2026-11-10 for the new biomes (Jungle, Fields, Blossom Orchard, Blight, Battlefield) and their bosses. **Not used by the game yet**: nothing reads these files and they are not registered in the monster catalog. Each one is a single idle pose on a transparent background, about 64-73 px, facing left or front. Monster art for the new biomes comes after the new chapter release (monsters per biome: IDL-107, IDL-109, IDL-201; bosses: IDL-111, IDL-257).
