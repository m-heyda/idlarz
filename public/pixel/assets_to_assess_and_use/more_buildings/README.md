# more_buildings (58 buildings, 80x80)

"Tiny Top-Down Village" by Pixel-Deck (https://pixel-deck.com): 58 individually named buildings on an 80x80 transparent canvas, plus a title card (`Titel.png`, `text.png`: not assets) and the pack's own `README.txt` with the licence.

**Use for**

- Named buildings with a gameplay role: Adventurer's Guild (quests, IDL-203), General Store and Merchant House (merchant scene), Blacksmith and Glassmaker (crafting, the Glass Vial), Herbalist and Beekeeper (potion ingredients, Honey), Brewer, Potter, Tailor (crafting goods, IDL-227), Library and Scribe (glossary), Observatory (maps, Paragon), Temple and Church (rebirth).

**Assessment:** the best set for "what does this building do" because every file is named. 80 px is 1.67 tiles: use 2x of a 40 px redraw or place it over two tiles.
