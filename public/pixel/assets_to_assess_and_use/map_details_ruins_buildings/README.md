Same layout (`Assets`, `Assets_shadow`, `Assets_texture_shadow`, `Assets_texture_shadow_dark`, `*_source.png`).

- Battlefield (Brown, Blue-gray), Blight (White, Blue-gray with the glow), Jungle (overgrown), Tundra (Snow), lake and coast (Water), dry hills (Sand, Yellow).
- Glossary and discovery ideas (find a ruin, `docs/plan/22-glossary-and-mastery.md`) and the preview map (`docs/plan/15-leaderboard-and-world-preview.md`).
