# Assets to assess and use

Art that was added for later features and is **not used by the game yet**. Nothing reads these files; they are not registered in `src/config/pixelIcons.ts` or the item icon registry. Each folder has its own README with what is inside, the size, and what to use it for. Assessed 2026-11-09, trimmed 2026-11-16 (the `misc` pack and the `potions` pack were removed from the repository; the registered potion icons live in `items/consumable/`), trimmed again 2026-11-19 by the owner (the `buildings`, `trees_mapp_details`, `minerals_map_details_or_resources_crafting_etc` and `monsters` packs were removed, and the ruins, fantasy-tree and rock packs lost their shadow variants and sheets; the pictures that were wired already live in `items/`, `icons/`, `rocks/` and `enemies/`). The game's map tile is 48 px (`TILE_SIZE` in `src/config/biomes.ts`).

## Before any of this ships (read this)

1. **Licences: all of these are free to use** (confirmed by the owner, 2026-11-09). Only `more_buildings` carries its licence text (Pixel-Deck: commercial use, modify and recolour allowed, attribution optional; **no reselling and no redistributing the complete pack unchanged**); for the other folders the pack names were not kept, so note the source of anything you use in its registry line or provenance.
2. **Keeping this folder in `public/` is fine** (owner decision, 2026-11-09): the game is non-commercial and its link is not public. Note for later: the Pixel-Deck term "do not redistribute the complete pack unchanged" applies to `more_buildings`, so revisit it if the game ever goes public or commercial. Practical tip: the folder is about 480 files now (many are shadow variants), so copy only the files that get used, recoloured to our palette, into `public/pixel/...` with a registry line.
3. **Style.** The map details (bushes, rocks, ruins, fantasy trees, misc) share one pack style: bright, outlined, soft ground shadow. The game's own map art is the procedural pipeline in `scripts/pixel`; bring these in through the same intake recipe (`scripts/pixel/extract_sheet.py`, nearest-neighbour, our palette) so the look stays consistent.
4. **Variants.** Most map-detail folders hold the same 40 objects four times (`Assets` = no shadow, `Assets_shadow` = soft shadow, `Assets_texture_shadow` and `Assets_texture_shadow_dark` = shadow on grass texture, light and dark) plus the source sheets. Use one variant per biome ground and drop the rest when you move the used files.
