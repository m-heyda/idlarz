## Before any of this ships (read this)

1. **Licences: all of these are free to use** (confirmed by the owner, 2026-11-09). Only `more_buildings` carries its licence text (Pixel-Deck: commercial use, modify and recolour allowed, attribution optional; **no reselling and no redistributing the complete pack unchanged**); for the other folders the pack names were not kept, so note the source of anything you use in its registry line or provenance.
2. **This folder sits in `public/`, so it is deployed and public in the git repo.** That is 1,270 files (many are shadow variants) served to every visitor, and for `more_buildings` it conflicts with the pack's "do not redistribute the complete pack unchanged" term. Recommended: move the folder out of `public/` (for example `art_style_reference/to_assess/`, which is not deployed) and copy only the files that get used, recoloured to our palette, into `public/pixel/...` with a registry line.
3. **Style.** The map details (trees, bushes, rocks, minerals, ruins, misc) share one pack style: bright, outlined, soft ground shadow. The game's own map art is the procedural pipeline in `scripts/pixel`; bring these in through the same intake recipe (`scripts/pixel/extract_sheet.py`, nearest-neighbour, our palette) so the look stays consistent.
4. **Variants.** Most map-detail folders hold the same 40 objects four times (`Assets` = no shadow, `Assets_shadow` = soft shadow, `Assets_texture_shadow` and `Assets_texture_shadow_dark` = shadow on grass texture, light and dark) plus the source sheets. Use one variant per biome ground and drop the rest when you move the used files.
