# biomes (20 files)

Framed landscape vignettes, 80x80, generated by the owner with Sprite Fusion on 2026-11-10 ("Same Style" from one tundra frame). Registered in the asset library (category **Biomes**, Storybook `Assets/Biomes`). Names are `biome_<biome>_<n>.png`.

**In the game now:** the five rebirth biomes show one picture each in the "New land unlocked" window (`src/config/biomeArt.ts`, `RebirthUnlockModal`): `biome_jungle_1`, `biome_fields_1`, `biome_orchard_1`, `biome_blight_1`, `biome_battlefield_1`. Change the choice in `BIOME_ART`.
