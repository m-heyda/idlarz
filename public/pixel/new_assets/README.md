# new_assets (31 files)

Portraits and achievement badges generated by the owner with Sprite Fusion on 2026-11-10. All are 64x64 (one is 65x65), transparent or framed, pixel art with a limited palette. They are **registered in the asset library** (`scripts/assets/manifest.ts`, categories `portraits` and `ui`) but **not wired into the game yet**; the avatar picker (IDL-71, IDL-77) and the achievements window (IDL-73) read them when their PRs land. Licence: provided by the owner, free to use for the game (same terms as the rest of `public/pixel`).

Files were renamed from the numbers Sprite Fusion produced (`1.png` ... `34543543.png`) to descriptive names; the old number is in the table.

## Before it ships

Check the 65x65 file (`avatar_winged_helm_veteran.png`) and crop it to 64x64 if the frame is off by one pixel. Each avatar must stay readable at 20 px (HUD, ranking row); view them at that size before the final id assignment.
