# __reuse/skills (9 skill icons)

32x32 skill icons supplied by the owner on 2026-11-17, **not used by the game yet**: they are the pool for the Skills tab of the Hero window (a coming-soon screen today) and for the skill brainstorm. Heal and Stun already have their own icons (`icons/skill_heal.png`, `icons/skill_stun.png`).

| File | What | Idea |
| ---- | ---- | ---- |
| `evil_eye.png` | a dripping green eye | curse, debuff |
| `jade_spire.png` | a jade crystal spire | earth, shield, summon |
| `comet.png` | a blue comet with a gold tail | ranged strike |
| `starburst.png` | a white and gold burst | nova, area damage |
| `flame_hand.png` | a hand holding a flame | fire spell |
| `whirlwind.png` | a blue whirlpool column | water or wind spell, area |
| `chain_orbs.png` | gold orbs joined by a bolt | chain lightning |
| `green_swirl.png` | a green swirl with an eye | nature, poison |
| `void_meteor.png` | a purple meteor | dark spell |

The names and ideas are only suggestions. When one is wired, move it to `icons/` (or the folder of its kind) and register it in `src/config/pixelIcons.ts`.
